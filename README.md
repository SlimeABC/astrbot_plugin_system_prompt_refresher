# astrbot_plugin_system_prompt_refresher

在长对话中让模型重新遵守系统提示词，或在修改提示词后刷新生效。刷新前默认备份，刷新后继续原对话，不丢聊天记录。

> **注意：请先备份，以免出现问题。** 刷新会修改对话历史，删除对话不可恢复。使用前请先备份当前对话（WebUI“备份对话”或 `copy_chat confirm`），并备份 AstrBot 数据目录。

## WebUI 的用途：静默刷新

WebUI 刷新**不会在聊天里发任何消息**，也不会触发 LLM。群友看不到任何提示，适合在群里悄悄刷新系统提示词。

对话内命令 `refresh_prompt confirm` 会由机器人回复一条结果消息，更适合私聊或不需要隐藏的场景。

## 安装

1. 插件目录放到 `AstrBot/data/plugins/`
2. WebUI → 插件 → 重载插件
3. 打开 WebUI → 插件 → 系统提示词刷新

## 使用

**WebUI（推荐，群友看不到）**

- 选择对话 →“刷新提示词”→ 确认；只会使用该对话最近一次聊天记录的提示词，没聊过就先发一条消息
- “备份对话”可自定义备份名称，默认 `原标题_backup`
- “删除对话”不可恢复，需要二次确认并双击确认按钮

**对话内**

```text
refresh_prompt confirm   # 刷新
copy_chat confirm        # 只备份
```

私聊直接发送；群聊需要 @机器人或唤醒词。默认仅管理员可用。

## 配置

指令名、确认词、管理员限制、备份开关、快照长度、回复文案、主题色等都在插件配置里，按需修改即可。

## 注意

> **温馨提示：切换对话请先安装 Builtin Commands Extension 插件。**

- **使用前请先备份**：刷新前虽然默认自动备份，但删除对话不可恢复，建议同时备份 AstrBot 数据目录
- 刷新会在对话历史末尾写入一条系统提示词快照，该快照会出现在对话记录中
- 备份会多保留一份完整历史，占用数据库空间
- 刷新后的几条消息缓存命中率会降低，可能产生额外费用；缓存重建后会恢复
- 本插件不修改 AstrBot 的人格配置
